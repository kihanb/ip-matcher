# IP Matcher — سپر هوشمند رفع تحریم و هماهنگی سیستم

ابزار دسکتاپ هوشمند برای ویندوز که به‌صورت لحظه‌ای آی‌پی عمومی سیستم را تشخیص می‌دهد، آن را با تنظیمات داخلی ویندوز مقایسه می‌کند و با یک کلیک (یا به‌صورت خودکار) ناهماهنگی‌های لو دهنده موقعیت واقعی کاربر را برطرف می‌کند.

## قابلیت‌های کلیدی

- **تشخیص لحظه‌ای آی‌پی و موقعیت مکانی:** پشتیبانی از چند سرویس‌دهنده (`ip-api.com`، `ipwho.is`، `ipapi.co`) و پشتیبانی از پروکسی سیستم، اتصال مستقیم یا پروکسی سفارشی (`SOCKS5` / `HTTP` مثل `v2rayN` و `Clash`).
- **هماهنگ‌سازی کامل سیستم‌عامل:**
  - منطقه زمانی ویندوز (`tzutil`) و ساعت سیستم (`w32tm` در حالت مدیر)
  - کشور سیستم (`Windows Home Location / GeoID`)
  - فرمت منطقه‌ای و واحد پول (`Culture`)
  - اولویت زبان سیستم و مرورگر (`WinUserLanguageList`) با حفظ کیبورد فارسی (`fa-IR`) به‌عنوان زبان دوم
  - مسدودسازی دسترسی موقعیت مکانی ویندوز (`Location Consent`) برای جلوگیری از نشت Wi-Fi/GPS
  - تشخیص نشت `DNS` و `IPv6` و امکان تنظیم DNS ضدنشت
- **ذخیره تنظیمات قبلی و بازگشت یک‌کلیکی:**
  - ثبت خودکار **حالت اولیه سیستم (Baseline)** در اولین اجرا
  - ذخیره خودکار اسنپ‌شات پیش از هر تغییر برای **بازگشت سریع (Undo)**
  - ایجاد، نام‌گذاری، خروجی و ورود پروفایل‌های سفارشی (`JSON`)
- **حالت هوشمند (Smart Auto-Sync) و System Tray:** پایش پس‌زمینه برای تشخیص تغییر آی‌پی VPN و همگام‌سازی خودکار.
- **لانچر مرورگر ایزوله:** اجرای پروفایل مجزای Edge یا Chrome هماهنگ با زبان و پروکسی کشور مقصد.
- **رابط کاربری دوزبانه (فارسی راست‌چین / انگلیسی)** با پشتیبانی از پوسته تیره و روشن.

## اجرا

```powershell
python main.py
```

یا از طریق فایل `run_ip_matcher.bat` برنامه را اجرا کنید. برای اعمال تنظیمات سطح سیستم مثل همگام‌سازی سرویس زمان (`NTP`) و تغییر `DNS`، می‌توانید از دکمه **«ارتقا به مدیر»** درون برنامه استفاده کنید.
